IRON FOX STUDIO — обновлённые страницы Games и About

Файлы:
- HTMLPage2.html — страница Games
- About.html — страница About

Что изменено:
- Добавлен отдельный слой CSS для глубины, стеклянных панелей, свечения, космического фона и анимации карточек.
- Сохранены исходные ссылки на игры, логотип-текст, Firebase.js и скрипты universe.
- Мобильная сетка адаптируется в одну колонку.
- Учитывается prefers-reduced-motion.

Установка:
1. Сделайте резервную копию текущих HTMLPage2.html и About.html.
2. Замените ими соответствующие файлы из архива.
3. Оставьте остальные ресурсы проекта на месте: папку Images, Firebase.js, universe.css, universe.js, page-universe.css, page-universe.js, ironfox-3d-pages.css и другие используемые файлы.

Примечание:
Эта версия создаёт 3D-ощущение через CSS-перспективу, слои, свет и анимации; это не WebGL/Three.js-сцена.
Проверьте страницы в своём браузере после замены.
